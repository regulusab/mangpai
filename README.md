# 盲派八字論命

https://regulusab.github.io/mangpai/

這是盲派八字排盤與命書網站。

- **排盤**：命盤版面依範本第 1 頁的格式。
- **產生命書**：章節順序依範本，另外增加「盲派結構論斷（本站增補）」一章。
- **下載**：命書可下載 PDF 與 Word。

## 指令

- `npm run dev`：開發
- `npm run build`：建置
- `npm run preview`：預覽，網址為 http://localhost:4174/mangpai/
- `npm run qa`：資料比對、PDF／Word 檢查，以及桌機與手機截圖，輸出到 /workspace/fig/mangpai/
